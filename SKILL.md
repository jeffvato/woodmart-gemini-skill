# WoodMart Development & Design Skill

This skill guides the creation and customization of high-performance e-commerce sites using the WoodMart WordPress theme.

## 1. Core Principles
- **Child-Theme First:** All modifications MUST happen in the `woodmart-child` directory.
- **Visual Builder Integration:** Expert use of Elementor/WPBakery for layout management.
- **SEO & LLM Ready:** Maximize visibility for Google and AI models via semantic HTML and Schema.org.

## 2. Workflows

### Layout & Header Building
1. **Header Builder:** Access via **WoodMart > Header Builder**. Use for top bars, logos, and custom navigation blocks.
2. **HTML Blocks:** Use for reusable content (footers, mega menus, banners). Create under **HTML Blocks > All Items**.
3. **WooCommerce Layouts:** Design custom shop, single product, and cart/checkout pages without deep coding.

### Theme Styling
1. **Theme Settings:** Control typography, colors, and button styles globally.
2. **CSS Customization:** Use WoodMart's CSS variables (e.g., `--wd-primary-color`) for design consistency.
3. **Settings Presets:** Apply different designs to specific categories or pages.

### E-commerce Performance
1. **AJAX Everything:** Use built-in AJAX for filters, search, and "add to cart."
2. **Asset Optimization:** Manage CSS/JS files and images under **Theme Settings > Performance**.
3. **360 Degree Views:** Configure for complex product displays.
